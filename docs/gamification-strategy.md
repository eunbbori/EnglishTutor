# [전략 제안서] Daily English 게이미피케이션 & 수익화 전략

> **문서 유형**: Product Strategy Proposal
> **작성 기준**: PRD v2.0 + Functional Specification v1.0 분석 기반
> **작성일**: 2026-01-31

---

## TL;DR

현재 Daily English는 **"쓰면 교정해주는 도구"**에 머물러 있다. Streak 숫자와 캘린더 색칠 정도의 게이미피케이션은 초기 리텐션에 도움이 되지만, **2주차 이후 급격한 이탈(Churn Cliff)**을 막지 못한다. 이 문서는 "도구"를 **"매일 열고 싶은 게임"**으로 전환하는 구체적 전략을 제안한다.

## 1. Core Loop & Gamification (재미와 습관)

### 1.1 현재 상태 진단

| 요소 | 현재 구현 | 문제점 |
|------|-----------|--------|
| Streak | 연속 일수 카운터 + 불꽃 아이콘 | 숫자만 올라가고, 끊기면 복구 불가. 5일차에 끊기면 "다시 1부터" → 이탈 |
| 챌린지 모드 | 20개 단어 순환 | 20일이면 한 바퀴. 단어 수준이 고정이라 초보/중급 구분 없음 |
| 캘린더 | GitHub 잔디식 기분 표시 | 수동적 기록. "채워야 한다"는 의무감만 줌 |
| 보상 | 없음 | 쓰면 교정 결과가 나오는 것 외에 아무 보상이 없음 |

**핵심 문제**: Trigger → Action → Variable Reward → Investment의 Hook Model에서 **Variable Reward가 완전히 부재**하다. 매번 "교정 결과"라는 동일한 포맷의 보상만 돌아온다.

### 1.2 제안: 3-Layer Gamification System

#### Layer 1: XP(경험치) & 레벨 시스템

일기를 쓰는 모든 행동에 XP를 부여한다. XP는 레벨업의 유일한 통화다.

| 행동 | XP | 설명 |
|------|-----|------|
| 일기 제출 | +30 XP | 기본 보상 |
| 챌린지 단어 사용 | +15 XP | 챌린지 모드에서 오늘의 단어를 실제로 쓴 경우 |
| 오답 0개 교정 | +20 XP | "완벽한 일기" 보너스. 실력 향상의 체감 |
| 표현노트 저장 | +5 XP | 표현노트 활용 유도 |
| 연속 7일 달성 | +100 XP | 주간 마일스톤 보너스 |
| 연속 30일 달성 | +500 XP | 월간 마일스톤 보너스 |

**레벨 구간 설계** (로그 곡선, 초반 빠른 레벨업 → 후반 완만):

| 레벨 | 칭호 | 필요 XP (누적) | 예상 도달 기간 |
|------|------|---------------|---------------|
| 1-5 | Diary Beginner | 0 ~ 300 | 1~5일 |
| 6-10 | Daily Writer | 300 ~ 1,000 | 2~3주 |
| 11-15 | Story Teller | 1,000 ~ 2,500 | 1~2개월 |
| 16-20 | Word Crafter | 2,500 ~ 5,000 | 3~4개월 |
| 21-25 | English Native | 5,000 ~ 10,000 | 6개월+ |
| 26-30 | Master Author | 10,000+ | 1년+ |

**구현 참고**: `user_profiles` 테이블에 `xp`(integer), `level`(integer) 컬럼 추가. 교정 완료 후 XP 갱신은 기존 streak 갱신과 동일한 비차단 패턴으로 처리.

#### Layer 2: Variable Reward — "오늘의 보물상자"

매일 첫 일기를 제출하면 **랜덤 보상**이 등장한다. Duolingo의 "보물상자"와 유사하지만, 영어 학습에 맞춘 보상.

| 보상 종류 | 확률 | 내용 | 목적 |
|-----------|------|------|------|
| XP 보너스 | 40% | +10~50 XP 랜덤 | 즉각적 도파민 |
| 오늘의 명언 | 25% | 유명 영어 명언 + 해석 카드 | 학습 가치 + 공유 가능 |
| 희귀 표현 카드 | 20% | 원어민이 자주 쓰는 표현 1개 (AI 생성) | 표현노트 자동 추가, 수집 욕구 |
| 스트릭 보호막 | 10% | "Streak Freeze" 1회 획득 | 후술하는 위기/구제 메커니즘 연동 |
| 레어 칭호 | 5% | 한정 칭호 (예: "Night Owl", "Weekend Warrior") | 희소성 기반 수집 |

**핵심**: 보상 확률이 가변적(Variable Ratio)이므로 "오늘은 뭐가 나올까?" 기대감이 생긴다. 슬롯머신의 심리학을 학습에 적용한 것.

#### Layer 3: 주간 & 월간 퀘스트

단순 "매일 쓰기"를 넘어, **목표 다양화**로 신선함을 유지한다.

**주간 퀘스트 (매주 월요일 갱신)** — 3개 중 2개 이상 완료 시 보너스 XP:

| 퀘스트 유형 | 예시 | 보상 |
|------------|------|------|
| 빈도 퀘스트 | "이번 주 5일 이상 일기 쓰기" | +150 XP |
| 챌린지 퀘스트 | "이번 주 챌린지 단어 3개 이상 사용하기" | +100 XP |
| 표현 퀘스트 | "이번 주 표현노트에 5개 이상 저장하기" | +80 XP |
| 길이 퀘스트 | "50단어 이상 일기 2회 쓰기" | +120 XP |
| 완벽 퀘스트 | "오답 0개 일기 1회 달성하기" | +200 XP |

**월간 챌린지**: "1월 챌린지: 감정 표현 마스터" — 해당 월의 테마 표현 10개를 일기에 사용하면 특별 배지 + 대량 XP. 매달 테마가 바뀌므로 장기 리텐션 확보.

### 1.3 위기 & 구제 메커니즘 (작심삼일 방지)

스트릭이 끊기는 순간이 이탈의 최대 위기점이다. 현재 시스템은 "2일 이상 공백이면 1로 초기화"라는 냉정한 처리만 있다.

#### 메커니즘 A: Streak Freeze (스트릭 보호막)

| 항목 | 설계 |
|------|------|
| 획득 방법 | 오늘의 보물상자에서 랜덤 획득 (10%), 유료 구매 (후술) |
| 보유 한도 | 최대 2개 |
| 동작 | 하루를 빠져도 스트릭이 유지됨 (자동 소비) |
| 표시 | 헤더의 불꽃 아이콘 옆에 방패 아이콘으로 보유 수 표시 |

**심리학적 근거**: "보호막이 있으니 빠져도 괜찮아"라는 안전감이 오히려 매일 쓰게 만든다. Duolingo에서 검증된 패턴. 보호막을 "아끼려는" 심리가 작동하여 결국 쓰게 됨.

#### 메커니즘 B: Comeback Bonus (복귀 보너스)

스트릭이 끊긴 사용자에게 **"다시 시작"의 심리적 비용**을 낮추는 장치.

| 조건 | 보너스 |
|------|--------|
| 3일 이상 미접속 후 복귀하여 일기 작성 | "Welcome Back" 카드 + 50 XP |
| 스트릭 리셋 후 3일 연속 작성 | "Comeback Kid" 칭호 + 100 XP |
| 스트릭 리셋 후 7일 연속 작성 | 이전 스트릭의 50% 복구 |

**핵심**: "끊겨서 의미 없어졌다" → "다시 시작하면 보상이 있다"로 프레이밍 전환.

#### 메커니즘 C: Push Notification 전략 (향후 앱 전환 시)

| 타이밍 | 메시지 예시 | 트리거 |
|--------|-----------|--------|
| 오후 8시 (미작성 시) | "오늘의 보물상자가 기다리고 있어요!" | 당일 일기 미제출 |
| 스트릭 위험 (오후 10시) | "스트릭 12일! 오늘 안 쓰면 리셋돼요 🔥" | 연속 5일+ 사용자가 당일 미제출 |
| 복귀 유도 (3일 미접속) | "보물상자 3개가 쌓였어요. 열어볼까요?" | 3일 이상 미접속 |

## 2. Monetization on Fun (재미의 유료화)

### 2.1 현재 수익 모델 진단

| 항목 | 현재 | 문제점 |
|------|------|--------|
| 무료 | 하루 3회 교정 | "3회"는 일기 앱 특성상 **1회면 충분한** 사용자가 대부분. 제한이 안 느껴짐 |
| 프리미엄 | ₩9,900/월, 무제한 교정 | "무제한 교정"의 가치를 느끼려면 하루 4회 이상 쓰는 파워 유저여야 함. 그런 사용자 비율은 극소 |
| 결과 | 예상 전환율 1~2% | 무료로 충분히 쓸 수 있으므로 결제 동기 부재 |

**진단**: 현재 paywall은 "기능 제한"이 아니라 "횟수 제한"인데, 대부분의 사용자가 횟수 제한에 도달하지 않는다. **재미 요소에 과금점을 만들어야** 한다.

### 2.2 제안: "Freemium Fun" 과금 구조

#### Tier 1: 무료 (Free)

| 항목 | 제공 |
|------|------|
| 일일 교정 | 1회 (3회에서 하향. 근거: 아래 설명) |
| 챌린지 모드 | 사용 가능 |
| 스트릭 | 기본 추적 |
| 보물상자 | 없음 |
| 주간 퀘스트 | 1개만 활성 |
| 표현노트 | 최대 20개 저장 |
| 레벨 시스템 | 레벨 10 상한 |

**무료 교정 횟수를 3→1로 줄이는 근거**:
- 일기 앱의 자연스러운 사용 패턴은 "하루 1회"
- 1회는 서비스 가치를 체험하기에 충분
- 2회 이상 쓰고 싶은 순간이 바로 "결제 트리거"
- 교정 횟수가 아닌 **게이미피케이션 제한**이 주요 과금점이 됨

#### Tier 2: 프리미엄 (Premium) — ₩6,900/월

| 항목 | 제공 |
|------|------|
| 일일 교정 | 무제한 |
| 보물상자 | 매일 1회 |
| 주간 퀘스트 | 3개 전체 활성 |
| 월간 챌린지 | 참여 가능 |
| 표현노트 | 무제한 저장 |
| 레벨 시스템 | 상한 없음 |
| Streak Freeze | 월 2개 자동 지급 |
| 적응형 교정 | 오답 분석 + 맞춤 피드백 |

**가격 ₩9,900 → ₩6,900으로 하향하는 근거**:
- 현재 ₩9,900은 한국 시장에서 Netflix Basic(₩5,500)보다 비쌈
- 습관 앱 결제 심리 가격선은 ₩5,000~₩7,000 (Duolingo Plus 한국 가격 참고)
- 낮은 가격 → 높은 전환율 → 더 큰 총 매출 (단가 < 볼륨)
- 목표 전환율: 5~8%

#### Tier 3: 인앱 소모품 (Premium 가입 무관)

이것이 **진짜 수익 엔진**이다. 게이미피케이션 요소 자체를 구매할 수 있게 한다.

| 상품 | 가격 | 효과 | 심리적 트리거 |
|------|------|------|--------------|
| Streak Freeze x1 | ₩1,500 | 하루 빠져도 스트릭 유지 | "30일 스트릭을 ₩1,500에 지킬 수 있다면?" — 손실 회피 |
| Streak Freeze x3 | ₩3,500 | 3회분 묶음 (16% 할인) | 번들 할인 효과 |
| XP 2배 부스터 (24h) | ₩1,000 | 24시간 동안 모든 XP 2배 | 레벨업 직전 사용자의 조급함 활용 |
| 보물상자 열쇠 x5 | ₩2,500 | 보물상자 5회 추가 오픈 | 수집욕 (희귀 표현 카드, 레어 칭호) |
| 추가 교정 1회 | ₩500 | 당일 교정 1회 추가 | 무료 사용자가 "오늘 한 번만 더" 쓰고 싶을 때 |

**핵심 수익 아이템은 Streak Freeze**. Duolingo의 사례에서 Streak Freeze가 IAP(In-App Purchase) 매출의 30% 이상을 차지한다는 것은 잘 알려져 있다. 사용자가 100일 스트릭을 쌓았을 때, 갑자기 바빠서 못 쓸 것 같으면 ₩1,500은 "안 쓸 수 없는 돈"이 된다.

### 2.3 결제 동선 최적화

| 시점 | 트리거 | 제시 상품 |
|------|--------|----------|
| 무료 교정 소진 시 | "오늘의 교정을 다 썼어요" 모달 | 추가 교정 ₩500 (원버튼) + 프리미엄 ₩6,900 (하단) |
| 스트릭 끊긴 직후 | "스트릭이 리셋됐어요 😢" 알림 | Streak Freeze 구매 + "다음부터 자동 보호" 프리미엄 |
| 레벨업 직전 | "레벨 11까지 50 XP 남았어요!" | XP 2배 부스터 ₩1,000 |
| 레벨 10 도달 (무료 상한) | "더 높은 레벨에 도전하세요" | 프리미엄 구독 안내 |
| 표현노트 20개 도달 | "표현노트가 가득 찼어요" | 프리미엄 구독 안내 |

## 3. Feature Audit (기능 구조조정)

### 3.1 KILL — 삭제 또는 대폭 축소 제안

#### Kill 1: 오늘의 주제 힌트 (쓰기 모드)

| 항목 | 내용 |
|------|------|
| 현재 | 10종 고정 주제를 날짜 기반으로 순환, 무제한 셔플 |
| 문제 | 10개의 고정 주제는 2주면 전부 봄. "오늘 하루 어땠나요?"류의 뻔한 질문은 영감을 주지 못함. 실제로 이 기능을 쓰는 사용자는 초반 2~3일 뿐이라고 예측 |
| 제안 | **삭제하고 챌린지 모드로 통합**. 챌린지 모드의 "오늘의 단어"가 이미 "뭘 쓸지" 가이드 역할을 함. 쓰기 모드에서도 주제 힌트 대신 "오늘의 단어"를 선택적으로 표시하는 것이 단순하고 효과적 |
| 절감 효과 | 클라이언트 코드 단순화, 모드 전환 UX 간소화 |

#### Kill 2: 설명 수준 "간결 모드"

| 항목 | 내용 |
|------|------|
| 현재 | 상세(detailed) / 간결(concise) 2단계 |
| 문제 | "간결 모드"를 선택하는 중급 사용자는 이 앱의 타겟이 아님. 타겟은 "영어 일기를 처음 써보는" 초중급자. 두 가지 모드를 유지하면 AI 프롬프트 분기, 테스트 케이스, 사용자 설정 UI 등 복잡도만 증가 |
| 제안 | **"상세 모드"만 유지**. 대신 사용자의 레벨이 올라가면 AI가 자동으로 설명 깊이를 조절 (레벨 1~10: 매우 상세 / 레벨 11~20: 중간 / 레벨 21+: 핵심만). 이것이 진정한 "적응형" |
| 절감 효과 | 사용자 프로필 설정 UI 간소화, 프롬프트 분기 제거 |

#### Kill 3: 대화 메모리의 복잡한 3단계 구조 (간소화)

| 항목 | 내용 |
|------|------|
| 현재 | 체크포인트(단기) + 대화 요약(중기) + 사용자 프로필(장기) 3단계 |
| 문제 | 일기 앱에서 "대화"는 사실상 1회성이다. 사용자는 매일 새 일기를 쓰고, 이전 대화를 이어가지 않는다. 3단계 메모리는 챗봇용 설계이지 일기 앱에는 과잉 |
| 제안 | **사용자 프로필(장기)만 유지하고, 체크포인트와 대화 요약은 제거**. 매 교정은 독립적 요청으로 처리하되, 사용자의 오답 패턴과 레벨만 프롬프트에 반영. LangGraph 의존도를 낮추면 응답 속도도 개선됨 |
| 절감 효과 | 인프라 비용 절감 (LLM 요약 호출 제거), 응답 지연 감소, 코드 복잡도 대폭 감소 |

### 3.2 UPGRADE — 무료 → 유료 전환 게이트

#### Upgrade 1: 표현노트 → 무료 20개 제한

| 항목 | 내용 |
|------|------|
| 현재 | 로그인 사용자 무제한 저장 |
| 제안 | 무료 사용자는 **최대 20개까지만** 저장 가능. 21개째부터 "프리미엄에서 무제한 저장" 안내 |
| 근거 | 표현노트를 적극 활용하는 사용자는 학습 의지가 높은 세그먼트 → 전환율이 높을 것으로 예상. "내가 모은 표현을 더 저장할 수 없다"는 것이 강력한 과금 트리거 |

#### Upgrade 2: 오답 분석 → 프리미엄 전용

| 항목 | 내용 |
|------|------|
| 현재 | 모든 사용자에게 오답 분류 + 인사이트 제공 |
| 제안 | **기본 교정(교정문 + 한국어 설명)은 무료**. 오답 패턴 분석, 반복 오답 인사이트, 적응형 피드백은 **프리미엄 전용**. 무료 사용자에게는 "이 실수 패턴을 분석하려면 프리미엄이 필요합니다" 티저 표시 |
| 근거 | "당신의 약점이 뭔지 알려줄 수 있는데, 보시겠어요?" — 호기심 기반 과금. AI 튜터의 핵심 차별점을 과금점으로 전환 |

#### Upgrade 3: 일기 기록 조회 → 무료 최근 7일만

| 항목 | 내용 |
|------|------|
| 현재 | 최대 50건 전체 조회 |
| 제안 | 무료 사용자는 **최근 7일간의 기록만** 조회 가능. 그 이전은 "프리미엄에서 전체 기록 보기" |
| 근거 | "3개월 전에 내가 뭘 틀렸는지 보고 싶다" → 장기 사용자의 자연스러운 욕구. 이 욕구가 과금 트리거 |

## 4. New Killer Feature — "AI Pen Pal (AI 펜팔)"

### 4.1 컨셉

> **"일기를 쓰면, AI가 답장을 보낸다."**

현재의 AI는 **교정자(Corrector)** 역할만 한다. 문법을 고쳐주고 설명하는 것이 끝이다. 이것은 "빨간 펜 선생님"이지 "친구"가 아니다.

AI Pen Pal은 교정 결과 이후에 **AI가 사용자의 일기 내용에 대해 영어로 짧은 답장**을 보내는 기능이다. 마치 외국인 펜팔 친구가 내 일기를 읽고 공감하거나, 질문하거나, 자기 이야기를 들려주는 것처럼.

### 4.2 왜 이것이 "킬러"인가

| 기존 일기 앱 | Daily English + AI Pen Pal |
|-------------|---------------------------|
| 쓰기 → 교정 → 끝 | 쓰기 → 교정 → **답장 읽기** → **답장에 답하기(다음 일기)** |
| 일방향 | **쌍방향 루프** |
| "오늘 뭘 쓰지?" 고민 | "어제 AI가 물어본 질문에 답해야지" → **자연스러운 쓰기 동기** |
| 학습 도구 느낌 | **친구와 대화하는 느낌** |

**이 기능이 해결하는 3가지 문제**:
1. **"오늘 뭘 쓰지?" 문제** — AI 답장이 다음 일기의 주제가 됨
2. **정서적 유대 부재** — "나를 기억하는 친구"가 생김
3. **영어 읽기 연습 부재** — AI 답장을 읽는 것 자체가 리딩 연습

### 4.3 기능 상세

#### 답장 생성 규칙

| 항목 | 규칙 |
|------|------|
| 생성 시점 | 교정 결과 반환 직후, 별도 비동기 생성 |
| 길이 | 사용자 일기의 50~80% 길이 (초보에게 너무 긴 영어는 부담) |
| 난이도 | 사용자 레벨에 맞춤. 레벨 1~10은 간단한 문장, 레벨 11+는 다양한 표현 |
| 한국어 비율 | 레벨에 따라 0~30% (핵심 어휘만 괄호 안에 한국어 병기) |
| 톤 | 친근한 친구. 격식 없이, 이모티콘 적절히 사용 |
| 내용 구성 | 공감(1문장) + 자기 이야기 또는 의견(1~2문장) + 질문(1문장) |

#### 답장 예시

사용자 일기:
> "Today I ate ramen for lunch. It was so hot but delicious. I always eat ramen when I feel tired."

AI Pen Pal 답장:
> "Oh, I love ramen too! 🍜 There's nothing better than hot soup on a cold day. I usually add an egg to mine — do you have a favorite topping? By the way, I hope you're not too tired today! What made you feel that way?"

#### 과금 설계

| 플랜 | 답장 |
|------|------|
| 무료 | 교정만 제공. 답장은 **미리보기 2줄**만 보이고, "전체 답장은 프리미엄에서" 안내 |
| 프리미엄 | 매일 전체 답장 수신. 답장 내 모르는 표현 탭하면 뜻 확인 (표현노트 연동) |

**이것이 최고의 과금 트리거인 이유**: 사용자는 이미 일기를 쓰고 교정을 받았다. 그런데 화면 하단에 "AI 친구의 답장"이 흐릿하게 보인다. **이미 투자한 시간(일기 쓰기) 대비 "읽기만 하면 되는" 보상**이 눈앞에 있는데 잠겨 있다. Sunk Cost + 즉각적 보상 기대 → 결제 전환.

### 4.4 구현 방향 (기술적 고려)

| 항목 | 방법 |
|------|------|
| AI 모델 | Gemini 2.0 Flash (빠른 응답, 비용 효율) |
| 프롬프트 | 교정 결과의 `correctedText` + `keywords` + `mood` + 사용자 레벨 기반 |
| 저장 | `messages` 테이블에 role: "penpal"로 저장 (기존 "assistant"와 구분) |
| 표시 | 교정 결과 하단에 "편지 봉투" UI로 답장 표시 |
| 히스토리 | 일기 상세 페이지에서 답장도 함께 표시 → "AI와의 교환일기" 느낌 |

## 5. 종합 로드맵 제안

### Phase 1: Foundation (즉시)
- XP & 레벨 시스템 구현 (DB 스키마 + 교정 후 XP 갱신)
- 무료 교정 횟수 3→1 조정
- 표현노트 20개 제한 (무료)
- 오답 분석 프리미엄 게이트
- "오늘의 주제 힌트" 제거, 챌린지 모드로 통합
- 설명 수준 설정 제거 → 레벨 기반 자동 조절

### Phase 2: Engagement (Phase 1 완료 후)
- Streak Freeze 시스템 (획득 + 유료 구매)
- 오늘의 보물상자 (Variable Reward)
- 주간 퀘스트 시스템
- Comeback Bonus 메커니즘
- 인앱 소모품 결제 연동

### Phase 3: Killer Feature (Phase 2 완료 후)
- AI Pen Pal 구현
- 답장 미리보기 + 프리미엄 잠금
- 월간 챌린지 시스템
- 히스토리에서 "교환 일기" 뷰

### Phase 4: Optimization (Phase 3 이후)
- A/B 테스트 (가격, 무료 횟수, 보상 확률 등)
- 코호트 분석 기반 퀘스트/보상 최적화
- 3단계 메모리 → 프로필 메모리만 유지 (기술 부채 정리)
- 대화 메모리 경량화 (LangGraph 의존도 축소)
