## Executive Summary

Daily English는 **"영어 일기를 게임처럼 매일 쓰게 만드는"** AI 교정 앱이다.

사용자가 짧은 영어 일기를 쓰면 AI가 즉시 교정하고, **XP/레벨/보물상자/스트릭/퀘스트** 등 다층 게이미피케이션으로 매일 돌아오게 만든다. 교정 이후에는 **AI 펜팔 친구가 답장**을 보내, "교정 도구"가 아닌 "교환 일기"로 사용자와 정서적 유대를 형성한다.

핵심 가치: **"틀려도 괜찮아요! 오늘의 보물상자를 열어보세요."**

### 비즈니스 모델 (BM)

Daily English는 **Freemium + IAP(In-App Purchase) 하이브리드 모델**로 수익을 창출한다.

| 수익원 | 설명 | 목표 비중 |

# Feature 1: 영어 일기 작성 & AI 교정

## 1. 배경 및 목적 (Background & Goal)

영어 학습의 가장 큰 장벽은 "쓸 기회의 부재"와 "틀릴까 봐 두려움"이다. Daily English는 매일 부담 없이 일기를 쓰고, AI가 즉각적인 교정과 격려를 제공하여 "매일 쓰는 습관"을 형성한다.

**수익화 관점**: 일기 교정은 제품의 **핵심 가치이자 최초 Hook**이다. 무료 1회로 가치를 체험시키고, 2회 이상 쓰고 싶은 욕구가 프리미엄 전환의 첫 번째 트리거가 된다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 오늘 있었던 일을 영어로 쓰고 AI 교정을 받고 싶다. 그래야 실전 영작 실력이 느는다.
- **영어 초보로서**, 교정 결과를 한국어로 쉽게 설명받고 싶다. 문법 용어만 나열되면 이해가 안 된다.
- **바쁜 직장인으로서**, 2-3분 안에 쓰고 결과를 확인하고 싶다. 길게 공부할 시간이 없다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 일기 작성 `[Free-Limited]`

| 기능 | 설명 | 태그 |
|------|------|------|
| 자유 작성 | 텍스트 영역에 영어 일기를 자유롭게 작성 | `[Free]` |
| 기분 선택 | 6가지 기분(좋음/보통/슬픔/신남/피곤/불안) 중 하나를 선택하여 일기와 함께 저장 | `[Free]` |
| 오늘의 단어 표시 | 챌린지 모드의 오늘의 단어를 작성 화면 상단에 선택적으로 표시. "뭘 쓸지" 가이드 역할 | `[Free]` |
| 키보드 단축키 | 데스크톱에서 `Cmd+Enter`로 바로 제출 | `[Free]` |
| 일일 교정 횟수 | 무료 1회/일, 프리미엄 무제한 | `[Free-Limited]` |

### 3.2 AI 교정 결과 `[Free]`

| 항목 | 설명 | 태그 |
|------|------|------|
| 원문 | 사용자가 쓴 영어 원문 | `[Free]` |
| 교정문 | 자연스러운 영어로 교정된 문장 | `[Free]` |
| 한국어 설명 | 교정 이유를 한국어로 친근하게 설명 (칭찬 먼저 → 교정 설명) | `[Free]` |

### 3.3 레벨 기반 적응형 설명 `[Free]`

사용자가 수동으로 설명 수준을 설정하는 대신, **XP 레벨에 따라 AI가 자동으로 설명 깊이를 조절**한다.

| 레벨 구간 | 한국어 비율 | 특징 |
|-----------|------------|------|
| Lv. 1~10 (Beginner) | 70-90% | 간단한 어휘, 단계별 분석, 충분한 예시, 격려 톤 |
| Lv. 11~20 (Intermediate) | 50-70% | 핵심 교정 포인트 위주, 적절한 영어 사용 |
| Lv. 21+ (Advanced) | 30-50% | 핵심만 간결하게, 영어 중심 설명 |

## 4. 정책 및 제약사항 (Policies)

### 입력 검증 (클라이언트 사이드) `[Free]`

XP/스트릭 어뷰징 방지 및 AI API 비용 절감을 위해, 제출 전 클라이언트에서 다음 규칙을 검증한다. 모든 검증은 서버 호출 없이 프론트엔드에서 처리한다.

| 규칙 | 조건 | 실패 시 안내 메시지 |
|------|------|-------------------|
| 빈 텍스트 금지 | `text.trim().length === 0` | 버튼 비활성화 (메시지 없음) |
| 최소 글자 수 | 공백 제외 20자 이상 | "조금 더 써볼까요? 최소 20자 이상 입력해주세요." |
| 최소 단어 수 | 공백 기준 5단어 이상 | "문장을 조금 더 만들어보세요! 최소 5단어 이상 필요해요." |
| 반복 문자 감지 | 동일 문자가 5회 이상 연속 (예: "aaaaa") | "의미 있는 영어 문장을 써주세요." |
| 반복 단어 감지 | 전체 단어 중 동일 단어 비율이 70% 이상 (예: "hello hello hello hello hello") | "다양한 단어로 일기를 써보세요!" |

**검증 흐름**: 사용자가 입력할 때마다 실시간으로 검증 → 미충족 시 제출 버튼 비활성화 + 입력 영역 하단에 안내 메시지 표시.

### 일반 정책

- 비로그인 사용자도 교정 기능 사용 가능 (단, 기록 저장 안 됨)
- **무료 사용자: 하루 1회 교정 가능. 초과 시 추가 교정권(₩500) 또는 프리미엄 업그레이드 안내**
- AI 응답 실패 시 "오류가 발생했습니다. 다시 시도해주세요." 안내
- API 타임아웃: 최대 60초

# Feature 2: 챌린지 모드 & 일일 미션

## 1. 배경 및 목적 (Background & Goal)

"쓸 말이 없다"는 것이 매일 일기를 쓰지 않는 가장 큰 이유다. 챌린지 모드는 **매일 하나의 영어 단어를 제시하고, 그 단어를 자연스럽게 일기에 써보는 미션**을 통해 "오늘 뭘 쓰지?" 고민을 해결하고, XP 보상으로 성취감을 부여한다.

**수익화 관점**: 챌린지 단어 사용 시 추가 XP(+15)를 제공하여 레벨업 속도에 영향. 무료 레벨 상한(Lv.10) 도달을 앞당기는 역할.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 매일 새로운 단어를 배우고 직접 써보고 싶다. 단어장만 보면 잊어버린다.
- **영어 초보로서**, "오늘 뭘 쓰지?" 고민 없이 미션을 따라 쓰고 싶다.
- **성취감을 원하는 사용자로서**, 미션 완료 XP를 받고 뿌듯함을 느끼고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 오늘의 단어 `[Free]`

- 매일 자정에 새로운 단어가 갱신된다 (20종 순환).
- 단어마다 **한국어 뜻**과 **예문**을 함께 제공한다.
- 일기에 해당 단어를 쓰면 실시간으로 **완료 체크**가 표시된다.
- 완료 시 **+15 XP** 보상.
- 단어 예시: grateful(감사하는), accomplish(성취하다), exhausted(지친), inspired(영감을 받은), comfortable(편안한) 등 **일기에 자주 쓰이는 감정/상태 표현** 위주.

### 3.2 프롬프트 변경 제한 `[Free]`

- 챌린지 모드에서 주제 변경은 **하루 3회**로 제한한다.
- 날짜가 바뀌면 변경 횟수가 자동 초기화된다.

## 4. 정책 및 제약사항 (Policies)

- 오늘의 단어 사용 여부는 대소문자 무시, 단어 경계 기준으로 판정
- 프롬프트 변경 횟수는 브라우저 로컬 저장소에 관리 (서버 동기화 없음)
- 로컬 저장소 데이터 손상 시 0회로 초기화

# Feature 3: XP & 레벨 시스템

## 1. 배경 및 목적 (Background & Goal)

단순히 "일기를 쓴다"는 행위에 **정량적 진행감(Progression)**을 부여해야 사용자가 성장을 체감한다. Duolingo, Habitica 등 글로벌 습관 앱이 증명하듯, XP와 레벨은 가장 기본적이면서 강력한 동기 부여 장치다.

**수익화 관점**: 무료 사용자의 레벨 상한을 Lv.10으로 제한하여, "더 높은 레벨에 도전하고 싶다"는 욕구를 프리미엄 전환 트리거로 활용한다. XP 2배 부스터는 IAP 수익원이다.

## 2. 유저 스토리 (User Stories)

- **성장을 체감하고 싶은 학습자로서**, 일기를 쓸 때마다 XP가 쌓이고 레벨이 올라가는 것을 보고 싶다.
- **경쟁심이 있는 사용자로서**, 칭호(Diary Beginner → Master Author)가 바뀌는 것을 목표로 매일 쓰고 싶다.
- **보상을 원하는 사용자로서**, 특정 행동(챌린지 완료, 완벽한 일기 등)에 추가 XP를 받아 빠르게 레벨업 하고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 XP 획득 규칙 `[Free-Limited]`

| 행동 | XP | 태그 |
|------|-----|------|
| 일기 제출 | +30 XP | `[Free]` |
| 챌린지 단어 사용 | +15 XP | `[Free]` |
| 오답 0개 교정 (완벽한 일기) | +20 XP | `[Free]` |
| 표현노트 저장 | +5 XP | `[Free]` |
| 연속 7일 달성 마일스톤 | +100 XP | `[Free]` |
| 연속 30일 달성 마일스톤 | +500 XP | `[Free]` |
| 주간 퀘스트 완료 | +80~200 XP | `[Pro]` |
| 월간 챌린지 완료 | +1,000 XP | `[Pro]` |
| XP 2배 부스터 (24h) | 위 모든 XP 2배 적용 | `[IAP]` |

로그 곡선 설계: 초반 빠른 레벨업 → 후반 완만. 무료 사용자는 **Lv.10 상한**.

| 레벨 | 칭호 | 필요 XP (누적) | 태그 |
|------|------|---------------|------|
| 1-5 | Diary Beginner | 0 ~ 300 | `[Free]` |
| 6-10 | Daily Writer | 300 ~ 1,000 | `[Free]` |

| 16-20 | Word Crafter | 2,500 ~ 5,000 | `[Pro]` |
| 21-25 | English Native | 5,000 ~ 10,000 | `[Pro]` |
| 26-30 | Master Author | 10,000+ | `[Pro]` |

### 3.3 레벨 표시 `[Free]`

| 기능 | 설명 |
|------|------|
| 헤더 표시 | 현재 레벨 + 칭호를 헤더에 표시 |

## 4. 정책 및 제약사항 (Policies)

- XP는 음수가 될 수 없음 (최소 0)
- 하루에 같은 행동을 반복해도 XP 부여 (단, 일기 제출 XP는 교정 건당 1회)
- XP/레벨 갱신 실패 시 교정 요청 자체는 정상 동작 (비차단)
- 무료 사용자가 Lv.10 이후 XP를 획득해도 레벨은 고정. 프리미엄 전환 시 누적 XP로 즉시 레벨 반영

# Feature 4: 스트릭 & 위기 구제 매커니즘

## 1. 배경 및 목적 (Background & Goal)

습관 형성에는 "연속성"이 핵심이다. Duolingo의 스트릭 시스템이 증명하듯, 연속으로 며칠 학습했는지 숫자로 보여주는 것만으로도 이탈률이 크게 줄어든다. 사용자는 한 번 쌓은 연속 기록을 깨고 싶지 않다는 심리(손실 회피)를 활용한다.

**그러나 스트릭만으로는 부족하다.** 스트릭이 끊기는 순간이 이탈의 최대 위기점이다. v3.0에서는 **Streak Freeze(보호막)**와 **Comeback Bonus(복귀 보너스)**를 추가하여, "끊겨도 돌아올 이유"를 만든다.

**수익화 관점**: Streak Freeze는 **IAP 최대 수익원**이다. 30일 스트릭을 쌓은 사용자가 바빠서 못 쓸 것 같을 때, ₩1,500으로 스트릭을 지킬 수 있다면 대부분 결제한다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 연속으로 며칠 째 일기를 쓰고 있는지 한눈에 보고 싶다. 기록이 쌓이는 게 동기 부여가 된다.
- **바쁜 직장인으로서**, 가끔 못 쓸 날이 있는데 스트릭이 리셋되면 의욕이 꺾인다. 보호막이 있으면 안심된다.
- **이탈했다 복귀한 사용자로서**, 다시 시작했을 때 "Welcome Back" 보상이 있으면 동기 부여가 된다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 연속 작성 스트릭 `[Free]`

| 기능 | 설명 |
|------|------|
| 연속 일수 표시 | 헤더에 불꽃 아이콘과 함께 현재 연속 작성 일수 표시 |
| 오늘 작성 여부 | 오늘 이미 일기를 썼으면 중복 카운트 방지 |
| 연속 판정 | 어제 썼으면 연속 +1, 2일 이상 공백이면 1로 초기화 (Streak Freeze 미보유 시) |
| 최장 기록 | 역대 최장 연속 기록을 별도로 보관 |
| 총 작성 수 | 누적 일기 작성 건수 |

### 3.2 Streak Freeze (스트릭 보호막) `[Pro]` `[IAP]`

| 항목 | 설명 |
|------|------|
| 획득 방법 | 보물상자에서 랜덤 획득 (10%), 프리미엄 월 2개 자동 지급, IAP 개별 구매 |
| 보유 한도 | 최대 2개 |
| 동작 | 하루를 빠져도 스트릭이 유지됨 (다음 날 판정 시 자동 소비) |
| 표시 | 헤더의 불꽃 아이콘 옆에 방패 아이콘으로 보유 수 표시 |
| IAP 가격 | Streak Freeze x1 = ₩1,500 / x3 묶음 = ₩3,500 |

### 3.3 Comeback Bonus (복귀 보너스) `[Free]`

스트릭이 끊긴 사용자에게 "다시 시작"의 심리적 비용을 낮추는 장치.

| 스트릭 리셋 후 7일 연속 작성 | 이전 스트릭의 50% 복구 |

# Feature 5: 오늘의 보물상자 (Variable Reward)

## 1. 배경 및 목적 (Background & Goal)

매번 "교정 결과"라는 동일 포맷의 결과만 돌아오면 도파민 반응이 줄어든다. Hook Model에서 **Variable Reward(가변 보상)**는 사용자가 "오늘은 뭐가 나올까?"라는 기대감을 갖게 만드는 핵심 장치다.

매일 첫 일기를 제출하면 **랜덤 보상**이 등장한다. 보상 종류와 양이 매번 달라지므로 기대감이 유지된다.

**수익화 관점**: 보물상자는 프리미엄 전용 기능. 무료 사용자에게는 "오늘의 보물상자가 기다리고 있어요" 메시지만 노출하여 업그레이드 동기 부여. 추가 보물상자 열쇠(x5 = ₩2,500)는 IAP 수익원.

## 2. 유저 스토리 (User Stories)

- **보상을 기대하는 사용자로서**, 일기를 쓸 때마다 랜덤 보상이 나오면 매일 열어보고 싶다.
- **수집욕이 있는 사용자로서**, 희귀 표현 카드나 레어 칭호를 모으고 싶다.
- **Streak Freeze가 필요한 사용자로서**, 보물상자에서 나오는 보호막을 아끼고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 보물상자 보상 풀 `[Pro]`

매일 첫 일기 제출 시 1회 자동 열림.

| 보상 종류 | 확률 | 내용 |
|-----------|------|------|
| XP 보너스 | 40% | +10~50 XP 랜덤 |
| 오늘의 명언 | 25% | 유명 영어 명언 + 해석 카드 (공유 가능) |
| 희귀 표현 카드 | 20% | 원어민이 자주 쓰는 표현 1개 (AI 생성, 표현노트 자동 추가) |
| Streak Freeze | 10% | 보호막 1회 획득 |
| 레어 칭호 | 5% | 한정 칭호 (예: "Night Owl", "Weekend Warrior") |

### 3.2 보물상자 열쇠 `[IAP]`

| 상품 | 가격 | 효과 |
|------|------|------|
| 보물상자 열쇠 x5 | ₩2,500 | 보물상자 5회 추가 오픈 |

### 3.3 보물상자 연출 `[Pro]`

| 기능 | 설명 |
|------|------|
| 오픈 애니메이션 | 상자가 흔들리며 열리는 1~2초 연출 |
| 보상 카드 | 보상 종류에 따른 카드 디자인 (일반/레어/에픽 등급 테두리) |

## 4. 정책 및 제약사항 (Policies)

- 하루 1회 자동 지급 (프리미엄 전용), 추가는 IAP 열쇠로만
- 무료 사용자에게는 보물상자 UI를 흐릿하게 표시 + "프리미엄에서 열어보세요" 안내
- 보상 확률은 서버에서 결정 (클라이언트 조작 방지)
- Streak Freeze 보유 상한(2개) 초과 시 XP 보너스로 대체

# Feature 6: 주간 & 월간 퀘스트

## 1. 배경 및 목적 (Background & Goal)

"매일 일기 쓰기"라는 단일 목표만으로는 신선함이 유지되지 않는다. 주간/월간 단위로 **다양한 미니 목표**를 제시하여, "이번 주에는 이것도 해볼까?"라는 부가 동기를 부여한다.

**수익화 관점**: 무료 사용자는 주간 퀘스트 1개만 활성. 프리미엄 사용자는 3개 전체 + 월간 챌린지 참여 가능. 퀘스트 XP 보상이 레벨업에 직접적으로 영향하므로, 무료 사용자의 레벨업 속도 차이가 프리미엄 전환 동기가 됨.

## 2. 유저 스토리 (User Stories)

- **목표 지향적인 사용자로서**, 주간 미션이 있으면 더 능동적으로 다양한 활동을 하게 된다.
- **장기 사용자로서**, 매달 바뀌는 챌린지가 있으면 새로운 주제에 도전할 수 있어 지루하지 않다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 주간 퀘스트 `[Free-Limited]`

매주 월요일 자정(KST)에 3개 갱신. 무료 사용자는 **1개만 활성**, 프리미엄은 **3개 전체**.

|------------|------|------|
| 빈도 퀘스트 | "이번 주 5일 이상 일기 쓰기" | +150 XP |
| 챌린지 퀘스트 | "이번 주 챌린지 단어 3개 이상 사용하기" | +100 XP |
| 표현 퀘스트 | "이번 주 표현노트에 5개 이상 저장하기" | +80 XP |
| 길이 퀘스트 | "50단어 이상 일기 2회 쓰기" | +120 XP |
| 완벽 퀘스트 | "오답 0개 일기 1회 달성하기" | +200 XP |

풀에서 3개를 무작위 선택하여 해당 주에 제공. 3개 중 2개 이상 완료 시 **주간 보너스 +100 XP**.

### 3.2 월간 챌린지 `[Pro]`

| 항목 | 설명 |

# Feature 7: AI Pen Pal (AI 펜팔)

## 1. 배경 및 목적 (Background & Goal)

현재의 AI는 **교정자(Corrector)** 역할만 한다. 이것은 "빨간 펜 선생님"이지 "친구"가 아니다. AI Pen Pal은 교정 결과 이후에 **AI가 사용자의 일기 내용에 대해 영어로 짧은 답장**을 보내는 기능이다. 마치 외국인 펜팔 친구가 내 일기를 읽고 공감하거나, 질문하거나, 자기 이야기를 들려주는 것처럼.

**이 기능이 해결하는 3가지 문제**:
1. **"오늘 뭘 쓰지?" 문제** — AI 답장 속 질문이 다음 일기의 주제가 됨
2. **정서적 유대 부재** — "나를 기억하는 친구"가 생김
3. **영어 읽기 연습 부재** — AI 답장을 읽는 것 자체가 리딩 연습

**수익화 관점**: AI Pen Pal은 프리미엄의 **최강 과금 트리거**다. 사용자는 이미 일기를 쓰고 교정을 받았다. 화면 하단에 "AI 친구의 답장"이 흐릿하게 보인다. 이미 투자한 시간(일기 쓰기) 대비 "읽기만 하면 되는" 보상이 잠겨 있다. Sunk Cost + 즉각적 보상 기대 → 결제 전환.

## 2. 유저 스토리 (User Stories)

- **교류가 그리운 학습자로서**, AI 친구가 내 일기에 답장을 보내주면 진짜 펜팔하는 느낌이라 매일 쓰고 싶다.
- **쓸 주제가 없는 사용자로서**, AI가 어제 답장에서 물어본 질문에 답하면 되니까 "뭘 쓰지?" 고민이 사라진다.
- **영어 읽기도 연습하고 싶은 사용자로서**, 내 수준에 맞는 영어 답장을 읽으며 자연스럽게 리딩 실력을 키우고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 답장 생성 `[Pro]` (무료: 미리보기 2줄)

| 항목 | 규칙 |
|------|------|
| 생성 시점 | 교정 결과 반환 직후, 별도 비동기 생성 |
| 길이 | 사용자 일기의 50~80% 길이 |
| 난이도 | 사용자 레벨에 맞춤. Lv.1~10은 간단한 문장, Lv.11+는 다양한 표현 |
| 한국어 비율 | 레벨에 따라 0~30% (핵심 어휘만 괄호 안에 한국어 병기) |
| 톤 | 친근한 친구. 격식 없이 자연스러운 영어 |
| 내용 구성 | 공감(1문장) + 자기 이야기 또는 의견(1~2문장) + 질문(1문장) |

### 3.2 답장 예시

사용자 일기:
> "Today I ate ramen for lunch. It was so hot but delicious. I always eat ramen when I feel tired."

AI Pen Pal 답장:
> "Oh, I love ramen too! There's nothing better than hot soup on a cold day. I usually add an egg to mine — do you have a favorite topping? By the way, I hope you're not too tired today! What made you feel that way?"

### 3.3 답장 표시 UI `[Free-Limited]`

| 기능 | 무료 | 프리미엄 |
|------|------|----------|
| 답장 카드 | 교정 결과 하단에 "편지 봉투" UI로 표시 | 동일 |
| 답장 내용 | **미리보기 2줄만** 표시, 나머지 흐릿한 블러 처리 | 전체 답장 표시 |
| 잠금 안내 | "전체 답장은 프리미엄에서 읽어보세요" | 표시 안 함 |
| 표현 탭 | 불가 | 답장 내 모르는 표현 탭 → 뜻 확인 + 표현노트 저장 |
| 히스토리 | 불가 | 일기 상세에서 답장도 함께 표시 → "교환 일기" 느낌 |

### 3.4 답장 맥락 기억 `[Pro]`

| 항목 | 설명 |
|------|------|
| 이전 답장 참조 | AI가 어제 답장에서 물어본 질문을 기억하고, 사용자가 답했는지 자연스럽게 반응 |
| 사용자 관심사 | 사용자가 반복적으로 쓰는 주제(음식, 직장 등)를 파악하여 답장에 반영 |
| 성장 격려 | 이전 일기 대비 발전된 표현을 감지하면 칭찬 |

## 4. 정책 및 제약사항 (Policies)

- 답장 생성은 교정과 독립적 (답장 생성 실패 시 교정 결과는 정상 반환)
- 답장 생성 타임아웃: 최대 15초 (교정 응답 이후 비동기이므로 사용자 체감 지연 없음)
- 무료 사용자도 답장 미리보기(2줄)는 항상 표시 — 과금 트리거 역할
- 부적절한 내용 요청 시 AI가 거부하고 일반적인 답장 생성

# Feature 8: 표현노트 (어휘 저장 & AI 보강)

## 1. 배경 및 목적 (Background & Goal)

교정 결과를 읽고 넘기면 대부분 잊어버린다. "이 표현 좋다!"라고 느끼는 순간에 즉시 저장해야 학습 효과가 극대화된다. 표현노트는 단순 저장을 넘어, AI가 자동으로 **한국어 뜻, IPA 발음, 품사, 동의어, 난이도**를 채워주어 완전한 학습 카드를 만들어준다.

**수익화 관점**: 무료 사용자는 **최대 20개**까지만 저장 가능. 표현노트를 적극 활용하는 사용자는 학습 의지가 높은 세그먼트이므로 전환율이 높을 것으로 예상된다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 교정 결과에서 좋은 표현을 드래그만으로 저장하고 싶다. 별도 앱을 오가면 흐름이 끊긴다.
- **복습하고 싶은 사용자로서**, 저장한 표현의 뜻과 발음을 한 곳에서 보고 싶다.
- **기록을 남기고 싶은 사용자로서**, 어떤 문장에서 이 표현을 배웠는지 원문 맥락을 다시 보고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 텍스트 선택 저장 `[Free-Limited]`

| 기능 | 설명 | 태그 |
|------|------|------|
| 드래그 저장 | 교정 결과 텍스트를 드래그 선택하면 "표현노트에 저장" 툴팁이 나타남 | `[Free]` |

# Feature 9: 반복 오답 분석 & 적응형 피드백 `[Pro]`

## 1. 배경 및 목적 (Background & Goal)

영어 학습자의 가장 큰 좌절감은 **"같은 실수를 계속 반복하는데, 뭘 틀리는지도 모른다"**는 것이다. 이 기능은 사용자의 오답 패턴을 자동으로 추적하고, 같은 실수가 반복되면 인사이트를 제공하며, 다음 교정 시 약점을 반영한 맞춤 피드백을 생성한다.

**수익화 관점**: 오답 분석은 프리미엄의 **핵심 차별 가치**다. 무료 사용자에게는 교정 결과에 "이 실수 패턴을 분석하려면 프리미엄이 필요합니다"라는 티저를 보여줌으로써 호기심 기반 과금을 유도한다.

## 2. 유저 스토리 (User Stories)

- **자주 틀리는 학습자로서**, AI가 "이 실수 이번 주에 3번째예요"라고 알려주면 경각심이 생긴다.
- **성장하고 싶은 학습자로서**, 내 약점이 뭔지 파악하고 집중적으로 개선하고 싶다.
- **맞춤 학습을 원하는 사용자로서**, AI가 내 수준과 약점을 기억해서 설명해주면 좋겠다.

## 3. 핵심 기능 요구사항 (Key Features)

# Feature 13: 사용자 프로필 관리

## 1. 배경 및 목적 (Background & Goal)

사용자의 학습 목표와 누적 데이터(XP, 레벨, 보유 아이템)를 관리하는 기능. v3.0에서는 설명 수준 수동 설정을 제거하고, **레벨 기반 자동 적응**으로 전환하였다. 프로필은 XP/레벨/인벤토리(Streak Freeze, 칭호 등)의 중앙 관리 역할을 한다.

## 2. 유저 스토리 (User Stories)

- **학습 목표가 있는 사용자로서**, 내 목표를 입력해서 그에 맞는 피드백을 받고 싶다.
- **진행 상황을 보고 싶은 사용자로서**, 내 레벨, XP, 보유 칭호, Streak Freeze 수를 한 곳에서 보고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

| 설정 항목 | 설명 | 태그 |
|-----------|------|------|
| 학습 목표 | "비즈니스 이메일", "일상 회화" 등 자유 입력 | `[Free]` |
| XP / 레벨 | 현재 XP, 레벨, 칭호 표시. 다음 레벨까지 남은 XP | `[Free]` |
| 보유 칭호 | 획득한 칭호 목록 (장착 가능) | `[Free]` |
| Streak Freeze 보유 수 | 현재 보유한 보호막 수 (최대 2개) | `[Free]` |
| 구독 상태 | Free / Premium 표시, 만료일 | `[Free]` |
| 구독 관리 | 프리미엄 가입/해지 링크 | `[Free]` |

## 4. 정책 및 제약사항 (Policies)

- 프로필 미존재 시 자동 생성 (기본값: Lv.1, XP 0, Free 플랜)
- 학습 목표 변경 즉시 반영 (다음 교정부터 적용)
- 프로필 조회 실패 시 기본 프롬프트로 동작
