## Executive Summary

Daily English는 **"매일 영어 일기를 쓰는 습관"**을 만들어주는 게이미피케이션 학습 앱이다.
사용자가 짧은 영어 일기를 쓰면 AI가 즉시 교정하고, 연속 작성 기록/챌린지/표현노트 등 게이미피케이션 요소로 매일 돌아오게 만든다.

핵심 가치: **"틀려도 괜찮아요! 매일 쓰는 게 중요해요."**

# Feature 1: 영어 일기 작성 & AI 교정

## 1. 배경 및 목적 (Background & Goal)

영어 학습의 가장 큰 장벽은 "쓸 기회의 부재"와 "틀릴까 봐 두려움"이다. 학원이나 회화 앱은 시간과 비용 부담이 크고, 혼자 영작을 하면 틀린 줄도 모르고 넘어간다.

Daily English는 매일 부담 없이 일기를 쓰고, AI가 즉각적인 교정과 격려를 제공함으로써 "매일 쓰는 습관"을 형성하는 것을 목표로 한다. 교정 결과는 단순 빨간 줄 긋기가 아니라, **왜 틀렸는지 한국어로 친근하게 설명**하고, **다른 표현 방법 3가지**를 함께 제시하여 학습 효과를 극대화한다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 오늘 있었던 일을 영어로 쓰고 AI 교정을 받고 싶다. 그래야 실전 영작 실력이 느는다.
- **영어 초보로서**, 교정 결과를 한국어로 쉽게 설명받고 싶다. 문법 용어만 나열되면 이해가 안 된다.
- **바쁜 직장인으로서**, 2-3분 안에 쓰고 결과를 확인하고 싶다. 길게 공부할 시간이 없다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 일기 작성

| 기능 | 설명 |
|------|------|
| 자유 작성 | 텍스트 영역에 영어 일기를 자유롭게 작성 |
| 기분 선택 | 6가지 기분(좋음/보통/슬픔/신남/피곤/불안) 중 하나를 선택하여 일기와 함께 저장 |
| 오늘의 주제 힌트 | 매일 10종의 주제(오늘 하루, 음식, 기억에 남는 순간 등) 중 하나를 자동 제안. "다른 주제 찾기"로 자유롭게 변경 가능 |
| 키보드 단축키 | 데스크톱에서 `Cmd+Enter`로 바로 제출 |

### 3.2 AI 교정 결과

| 항목 | 설명 |
|------|------|
| 원문 | 사용자가 쓴 영어 원문 |
| 교정문 | 자연스러운 영어로 교정된 문장 |
| 한국어 설명 | 교정 이유를 한국어로 친근하게 설명 (칭찬 먼저 → 교정 설명) |
| 대안 표현 3가지 | 같은 뜻을 Casual/Expressive/Simple 스타일로 각각 제시 |
| 주제 키워드 | 일기의 핵심 주제 키워드 (최대 3개, 캘린더에서 활용) |

### 3.3 적응형 설명 수준

사용자가 설정한 설명 수준에 따라 AI 교정의 상세도가 달라진다.

| 설명 수준 | 한국어 비율 | 특징 |
|-----------|------------|------|
| 상세 모드 (기본) | 70-90% | 간단한 어휘, 단계별 분석, 충분한 예시, 격려 톤 |
| 간결 모드 | 40-60% | 핵심 교정 포인트만, 효율적인 설명 |

## 4. 정책 및 제약사항 (Policies)

- 빈 텍스트는 제출 불가 (버튼 비활성화)
- 비로그인 사용자도 교정 기능 사용 가능 (단, 기록 저장 안 됨)
- 무료 사용자: 하루 3회 교정 가능. 초과 시 프리미엄 업그레이드 안내
- AI 응답 실패 시 "오류가 발생했습니다. 다시 시도해주세요." 안내
- API 타임아웃: 최대 60초

# Feature 2: 챌린지 모드 & 일일 미션

## 1. 배경 및 목적 (Background & Goal)

"쓸 말이 없다"는 것이 매일 일기를 쓰지 않는 가장 큰 이유다. 쓰기 모드(자유)만으로는 매일 동기 부여가 어렵다.

챌린지 모드는 **매일 하나의 영어 단어를 제시하고, 그 단어를 자연스럽게 일기에 써보는 미션**을 통해 "오늘 뭘 쓰지?" 고민을 해결하고, 게임적인 성취감을 부여한다. 새로운 어휘를 실제 문맥에서 써보는 것이 학습 효과가 높다는 연구에 기반한다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 매일 새로운 단어를 배우고 직접 써보고 싶다. 단어장만 보면 잊어버린다.
- **영어 초보로서**, "오늘 뭘 쓰지?" 고민 없이 미션을 따라 쓰고 싶다.
- **성취감을 원하는 사용자로서**, 미션 완료 표시를 보고 뿌듯함을 느끼고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 모드 선택

| 모드 | 설명 |
|------|------|
| 쓰기 모드 | 자유 주제로 일기 작성. 오늘의 주제 힌트 제공, 무제한 변경 가능 |
| 챌린지 모드 | 오늘의 단어를 활용한 일기 작성. 단어 사용 시 완료 표시 |

### 3.2 오늘의 단어

- 매일 자정에 새로운 단어가 갱신된다 (20종 순환).
- 단어마다 **한국어 뜻**과 **예문**을 함께 제공한다.
- 일기에 해당 단어를 쓰면 실시간으로 **완료 체크**가 표시된다.
- 단어 예시: grateful(감사하는), accomplish(성취하다), exhausted(지친), inspired(영감을 받은), comfortable(편안한) 등 **일기에 자주 쓰이는 감정/상태 표현** 위주.

### 3.3 프롬프트 변경 제한 (챌린지 모드)

- 챌린지 모드에서 주제 변경은 **하루 3회**로 제한한다.
- 날짜가 바뀌면 변경 횟수가 자동 초기화된다.
- 쓰기 모드에서는 주제 변경 횟수 제한 없음.

## 4. 정책 및 제약사항 (Policies)

- 오늘의 단어 사용 여부는 대소문자 무시, 단어 경계 기준으로 판정
- 프롬프트 변경 횟수는 브라우저 로컬 저장소에 관리 (서버 동기화 없음)
- 로컬 저장소 데이터 손상 시 0회로 초기화

# Feature 3: 연속 작성 스트릭

## 1. 배경 및 목적 (Background & Goal)

습관 형성에는 "연속성"이 핵심이다. Duolingo의 스트릭 시스템이 증명하듯, **연속으로 며칠 학습했는지 숫자로 보여주는 것만으로도 이탈률이 크게 줄어든다.** 사용자는 한 번 쌓은 연속 기록을 깨고 싶지 않다는 심리(손실 회피)를 활용한다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 연속으로 며칠 째 일기를 쓰고 있는지 한눈에 보고 싶다. 기록이 쌓이는 게 동기 부여가 된다.
- **습관을 만들고 싶은 사용자로서**, 연속 기록이 끊기지 않도록 매일 접속하게 된다.
- **성과를 확인하고 싶은 사용자로서**, 최장 연속 기록과 총 작성 수를 보고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

| 기능 | 설명 |
|------|------|
| 연속 일수 표시 | 헤더에 불꽃 아이콘과 함께 현재 연속 작성 일수 표시 |
| 오늘 작성 여부 | 오늘 이미 일기를 썼으면 중복 카운트 방지 |
| 연속 판정 | 어제 썼으면 연속 +1, 2일 이상 공백이면 1로 초기화 |
| 최장 기록 | 역대 최장 연속 기록을 별도로 보관 |
| 총 작성 수 | 누적 일기 작성 건수 |

## 4. 정책 및 제약사항 (Policies)

- 날짜 판정은 한국 시간(KST, UTC+9) 기준
- 하루에 여러 번 교정해도 연속 일수는 1만 증가
- 첫 작성 시 자동으로 스트릭 레코드 생성 (연속 1일)
- 스트릭 갱신 실패 시 교정 요청 자체는 정상 동작 (비차단)

# Feature 4: 표현노트 (어휘 저장 & AI 보강)

## 1. 배경 및 목적 (Background & Goal)

교정 결과를 읽고 넘기면 대부분 잊어버린다. **교정 중 눈에 띈 표현을 바로 저장할 수 있는 기능**이 필요하다. 특히 "이 표현 좋다!"라고 느끼는 순간에 즉시 저장해야 학습 효과가 극대화된다.

표현노트는 단순 저장을 넘어, AI가 자동으로 **한국어 뜻, IPA 발음, 품사, 동의어, 난이도**를 채워주어 별도 사전 검색 없이 완전한 학습 카드를 만들어준다.

## 2. 유저 스토리 (User Stories)

- **학습자로서**, 교정 결과에서 좋은 표현을 드래그만으로 저장하고 싶다. 별도 앱을 오가면 흐름이 끊긴다.
- **복습하고 싶은 사용자로서**, 저장한 표현의 뜻과 발음을 한 곳에서 보고 싶다.
- **기록을 남기고 싶은 사용자로서**, 어떤 문장에서 이 표현을 배웠는지 원문 맥락을 다시 보고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 텍스트 선택 저장

| 기능 | 설명 |
|------|------|
| 드래그 저장 | 교정 결과 텍스트를 드래그 선택하면 "표현노트에 저장" 툴팁이 나타남 |
| 원문 맥락 보존 | 표현이 사용된 전체 문장(교정문)을 함께 저장 |
| 토스트 알림 | 저장 성공/실패 시 화면 하단에 알림 표시 |

### 3.2 AI 자동 보강

저장 시 AI가 5초 이내로 다음 항목을 자동 생성한다:

| 보강 항목 | 설명 | 예시 |
|-----------|------|------|
| 한국어 뜻 | 문맥을 고려한 정확한 뜻 | "감사하는, 고마워하는" |
| IPA 발음 | 국제 음성 기호 표기 | /ˈɡreɪtfəl/ |
| 품사 | 영어 품사 분류 | adjective |
| 동의어 | 유사 표현 (최대 3개) | thankful, appreciative |
| 예문 | 원문과 다른 새로운 예문 | "I'm grateful for your support." |
| 난이도 | 학습 수준 분류 | beginner / intermediate / advanced |

### 3.3 표현노트 페이지

| 기능 | 설명 |
|------|------|
| 목록 표시 | 저장된 표현을 최신순으로 표시 |
| 검색 | 단어 또는 뜻으로 검색 |
| 원문 맥락 표시 | "내가 쓴 문장" 라벨과 함께 원문을 보여줌 |
| 삭제 | 개별 표현 삭제 (확인 대화상자) |

### 3.4 저장된 표현 하이라이트

- 교정 결과 페이지에서 이미 저장한 표현은 **노란색 배경으로 자동 하이라이트** 처리된다.
- 긴 구문을 우선 매칭하여 중복 하이라이트를 방지한다.

## 4. 정책 및 제약사항 (Policies)

- AI 보강 타임아웃 5초 초과 시 보강 없이 저장 진행 (사용자에게 보강 실패 여부 안내)
- 빈 단어는 저장 불가
- 동일 단어 중복 저장 허용 (별도 중복 검증 없음)
- 로그인 필수 기능 (비인증 시 401)

# Feature 5: 반복 오답 분석 & 적응형 피드백

## 1. 배경 및 목적 (Background & Goal)

영어 학습자의 가장 큰 좌절감은 **"같은 실수를 계속 반복하는데, 뭘 틀리는지도 모른다"**는 것이다. 기존 교정 도구는 매번 새로운 교정만 제공할 뿐, 사용자의 약점을 기억하거나 알려주지 않는다.

이 기능은 사용자의 오답 패턴을 자동으로 추적하고, **같은 실수가 반복되면 한국어 인사이트를 제공**하며, 다음 교정 시 **사용자의 약점을 반영한 맞춤 피드백**을 생성한다. AI 튜터가 "기억력"을 갖는 핵심 차별점이다.

## 2. 유저 스토리 (User Stories)

- **자주 틀리는 학습자로서**, AI가 "이 실수 이번 주에 3번째예요"라고 알려주면 경각심이 생긴다.
- **성장하고 싶은 학습자로서**, 내 약점이 뭔지 파악하고 집중적으로 개선하고 싶다.
- **맞춤 학습을 원하는 사용자로서**, AI가 내 수준과 약점을 기억해서 설명해주면 좋겠다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 오답 자동 분류

교정 시 AI가 오답을 다음 체계로 자동 분류한다:

| 대분류 | 세부 유형 | 설명 |
|--------|-----------|------|
| 문법 | 시제 오류 | 과거/현재/미래 시제 혼동 |
| 문법 | 주어-동사 수 일치 | 3인칭 단수 -s 누락 등 |
| 문법 | 전치사 오용 | in/on/at 등 잘못된 사용 |
| 문법 | 관사 오용 | a/an/the 누락 또는 오사용 |
| 문법 | 어순 오류 | 한국어식 어순 |
| 문법 | 단수/복수 | 복수형 -s 누락 등 |
| 표현 | 부자연스러운 표현 | 문법은 맞지만 원어민이 안 쓰는 표현 |
| 표현 | 직역 | 한국어를 그대로 번역 |
| 어휘 | 단어 선택 오류 | 맥락에 맞지 않는 단어 사용 |
| 어휘 | 어색한 단어 조합 | 자연스럽지 않은 콜로케이션 |

### 3.2 반복 오답 인사이트

동일 패턴이 **7일 이내에 3회 이상** 반복되면, 교정 결과에 격려형 인사이트 메시지를 추가한다.

**인사이트 메시지 예시:**
> "자주 틀리는 부분이에요 (3회)
>
> 일기는 보통 과거에 있었던 일을 쓰는 거라서, 과거 시제를 자주 써요. 'go -> went', 'eat -> ate' 같은 불규칙 과거형을 틈틈이 외워보세요!
>
> 매일 일기 쓰면서 자연스럽게 실력이 늘거에요! 오늘도 수고했어요"

### 3.3 적응형 AI 교정

다음 교정 요청 시 AI 프롬프트에 자동 반영되는 정보:

| 컨텍스트 | 반영 방식 |
|----------|-----------|
| 설명 수준 (상세/간결) | 한국어 비율과 설명 깊이를 조절 |
| 학습 목표 | 사용자가 설정한 목표에 맞춘 피드백 |
| 최근 7일 주요 오답 (TOP 3) | 약점 영역은 더 상세한 설명, 잘하는 영역은 간단히 |

### 3.4 오답 기록 관리

| 항목 | 설명 |
|------|------|
| 빈도 추적 | 동일 패턴의 발생 횟수를 자동 누적 |
| 예시 보관 | 실수한 문장을 최대 5개까지 보관 (최신 순) |
| 기간별 조회 | 최근 7일간의 주요 오답을 빈도순으로 조회 |

## 4. 정책 및 제약사항 (Policies)

- 오답 분류/저장 실패 시 교정 요청 자체는 정상 동작 (비차단 처리)
- 인사이트 생성 실패 시에도 교정 결과는 정상 반환
- 교정 결과에 오류가 없으면 (이미 자연스러운 영어인 경우) 오답 분류를 하지 않음
- 사용자 프로필 조회 실패 시 기본 프롬프트로 동작

# Feature 6: 캘린더 뷰 & 학습 시각화

## 1. 배경 및 목적 (Background & Goal)

"내가 얼마나 꾸준히 썼는지"를 시각적으로 확인하는 것은 습관 유지에 강력한 동기 부여가 된다. GitHub의 잔디(Contribution Graph)처럼, **캘린더에 작성한 날이 채워지는 것 자체가 보상**이 된다.

캘린더 뷰는 메인 화면의 첫 화면으로, 이번 달 작성 현황을 한눈에 보여주고 "오늘 아직 안 썼네, 써야지"라는 행동을 유도한다.

## 2. 유저 스토리 (User Stories)

- **습관을 만들고 싶은 사용자로서**, 이번 달 며칠이나 썼는지 달력으로 한눈에 보고 싶다.
- **과거 기록을 보고 싶은 사용자로서**, 특정 날짜에 어떤 일기를 썼는지 확인하고 싶다.
- **감정을 기록하는 사용자로서**, 그 날의 기분이 캘린더에 표시되면 감성적으로 좋겠다.

## 3. 핵심 기능 요구사항 (Key Features)

| 기능 | 설명 |
|------|------|
| 월별 캘린더 | 이번 달 달력에 일기를 쓴 날이 표시됨 |
| 기분 표시 | 작성한 날에 선택했던 기분 이모지가 표시됨 |
| 주제 키워드 | 그 날 일기의 핵심 키워드가 표시됨 (최대 3개) |
| 단어 수 | 작성한 일기의 단어 수 표시 |
| 미리보기 | 일기 원문 앞 100자를 미리보기로 표시 |
| 오늘 쓰기 | "오늘의 일기 쓰기" 버튼으로 작성 화면으로 전환 |
| 이전/다음 달 | 월 단위로 이동하여 과거 기록 확인 |

## 4. 정책 및 제약사항 (Policies)

- 날짜는 한국 시간(KST) 기준으로 표시
- 같은 날 여러 건 작성 시 마지막 항목만 캘린더에 표시
- 비인증 사용자도 캘린더 표시 가능 (게스트 ID 기반)
- 기분/키워드 파싱 실패 시 해당 정보 없이 표시

# Feature 7: 일기 기록 조회

## 1. 배경 및 목적 (Background & Goal)

과거에 쓴 일기를 다시 읽는 것은 **학습 복습**이자 **성장 확인**이다. "3개월 전에는 이렇게 틀렸는데, 지금은 안 틀린다"는 체감이 장기적 동기 부여의 핵심이다. 또한 교정 결과에서 놓쳤던 표현을 다시 저장할 기회를 제공한다.

## 2. 유저 스토리 (User Stories)

- **복습하고 싶은 사용자로서**, 과거 일기의 교정 결과를 다시 보고 싶다.
- **성장을 확인하고 싶은 사용자로서**, 시간순으로 과거 일기를 훑어보며 실력 변화를 느끼고 싶다.
- **표현을 저장하고 싶은 사용자로서**, 과거 교정 결과에서도 좋은 표현을 표현노트에 저장하고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

| 기능 | 설명 |
|------|------|
| 목록 표시 | 최신순으로 최대 50건의 일기를 목록 표시 |
| 미리보기 | 원문, 교정문, 한국어 설명 요약을 목록에서 확인 |
| 상세 보기 | 특정 일기를 클릭하면 전체 교정 결과(대안 표현, 인사이트 등)를 확인 |
| 표현 저장 | 상세 보기에서 텍스트 선택으로 표현노트에 저장 가능 |
| 저장 표현 하이라이트 | 이미 표현노트에 저장한 단어가 노란색으로 강조 표시 |

## 4. 정책 및 제약사항 (Policies)

- 로그인 필수 (비인증 시 빈 목록 + 게스트 표시)
- 최대 50건으로 제한 (페이지네이션 없음)
- 다른 사용자의 일기는 조회 불가 (소유권 검증)
- AI 응답 파싱 실패 항목은 목록에서 제외

# Feature 8: 대화 메모리 관리

## 1. 배경 및 목적 (Background & Goal)

AI 교정 품질은 "맥락을 얼마나 잘 기억하느냐"에 달려있다. 같은 사용자가 여러 번 일기를 쓰면, 이전 대화 내용과 사용자 특성을 반영한 교정이 훨씬 유용하다.

그러나 AI 모델에는 컨텍스트 윈도우 제한이 있어, 오래된 대화를 모두 넣을 수 없다. 이를 해결하기 위해 **3단계 메모리 시스템**을 운용한다: 단기(대화 체크포인트), 중기(대화 요약), 장기(사용자 프로필).

## 2. 유저 스토리 (User Stories)

- **반복 사용자로서**, AI가 내 이전 대화 맥락을 기억해서 더 정확한 교정을 해주면 좋겠다.
- **약점이 있는 사용자로서**, AI가 내 자주 하는 실수를 알고 그에 맞는 설명을 해주면 좋겠다.
- **장기 사용자로서**, 오래된 대화도 AI가 참고할 수 있으면 좋겠다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 3단계 메모리 구조

| 메모리 유형 | 저장 대상 | 갱신 시점 | 용도 |
|------------|----------|----------|------|
| 체크포인트 (단기) | 대화 상태 스냅샷 | 매 교정 시 | 대화 흐름 유지 |
| 대화 요약 (중기) | 오래된 대화의 LLM 요약 | 메시지 5개 초과 시 | 컨텍스트 윈도우 절약 |
| 사용자 프로필 (장기) | 반복 오답, 설명 수준, 학습 목표 | 오답 감지 시 | 적응형 교정 |

### 3.2 대화 요약

| 항목 | 설명 |
|------|------|
| 트리거 조건 | 대화 메시지가 5개를 초과할 때 |
| 요약 내용 | 주요 토픽, 교정 내용, 반복 오답, 설명된 문법 규칙 |
| 요약 길이 | 200자 이내 |
| 요약 후 유지 | 최근 3개 메시지만 원본 유지, 나머지는 요약으로 대체 |

## 4. 정책 및 제약사항 (Policies)

- 체크포인트/요약 저장 실패 시 교정 자체는 정상 동작 (비차단)
- 요약 LLM 실패 시 간단한 폴백 요약 생성 ("대화 N개 메시지 요약: ...")
- 메모리는 사용자에게 직접 노출되지 않음 (백그라운드 동작)

# Feature 9: 프리미엄 구독 & 사용량 관리

## 1. 배경 및 목적 (Background & Goal)

AI API 호출에는 비용이 발생하므로, **무료 사용량을 제한하고 프리미엄 구독으로 수익화**하는 프리미엄 모델이 필요하다. 동시에 무료 사용자도 충분히 서비스 가치를 체험해야 유료 전환이 일어난다.

하루 3회는 "맛보기에 충분하지만, 매일 쓰기엔 아쉬운" 적절한 제한이다.

## 2. 유저 스토리 (User Stories)

- **무료 사용자로서**, 하루 몇 번 교정을 받을 수 있는지 알고 싶다. 잔여 횟수를 보고 아껴 쓰고 싶다.
- **열정적인 사용자로서**, 제한 없이 마음껏 교정받고 싶어서 구독을 고려하고 싶다.
- **프리미엄 사용자로서**, 횟수 걱정 없이 자유롭게 사용하고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

### 3.1 사용량 제한

| 플랜 | 일일 교정 횟수 | 가격 |
|------|--------------|------|
| 무료 (Free) | 3회 | 무료 |
| 프리미엄 (Premium) | 무제한 | ₩9,900/월 |

### 3.2 사용 현황 표시

- 헤더에 잔여 사용 횟수를 표시한다 (데스크톱에서만 노출).
- 사용량 초과 시 프리미엄 업그레이드 모달을 표시한다.

### 3.3 결제 프로세스

| 단계 | 설명 |
|------|------|
| 업그레이드 모달 | 사용량 초과 시 또는 가격 페이지에서 표시 |
| Toss Payments 결제 | 카드/간편결제 등 다양한 결제 수단 지원 |
| 결제 승인 | 서버에서 금액(₩9,900) 검증 후 Toss API로 승인 |
| 구독 활성화 | 결제 성공 시 1개월간 프리미엄 상태 활성화 |
| 결제 성공/실패 | 전용 결과 페이지로 이동 |

### 3.4 구독 관리

| 기능 | 설명 |
|------|------|
| 구독 상태 확인 | 매 교정 요청 시 활성 구독 여부 확인 |
| 자동 만료 | 종료일 경과 시 자동으로 만료 처리 |
| 결제 취소 | 관리자가 API를 통해 취소 가능 (취소 사유 필수) |

## 4. 정책 및 제약사항 (Policies)

- 무료 사용량은 매일 자정(UTC) 기준 초기화
- 비인증(게스트) 사용자는 서버에서 사용량을 추적하지 않음 (프론트에서 처리)
- 결제 금액이 ₩9,900이 아닌 요청은 거부
- 구독 만료 시 자동으로 무료 플랜으로 전환 (데이터 삭제 없음)
- 구독 기간: 결제일로부터 정확히 1개월

# Feature 10: 사용자 프로필 관리

## 1. 배경 및 목적 (Background & Goal)

모든 사용자에게 동일한 교정 경험을 제공하면 초보자는 어렵고, 중급자는 지루하다. **설명 수준과 학습 목표를 사용자가 직접 설정**할 수 있게 하여, 자신에게 맞는 교정 경험을 받을 수 있도록 한다.

## 2. 유저 스토리 (User Stories)

- **영어 초보로서**, "상세 모드"로 설정해서 친절하고 쉬운 설명을 받고 싶다.
- **중급 이상 학습자로서**, "간결 모드"로 설정해서 핵심만 빠르게 확인하고 싶다.
- **학습 목표가 있는 사용자로서**, 내 목표를 입력해서 그에 맞는 피드백을 받고 싶다.

## 3. 핵심 기능 요구사항 (Key Features)

| 설정 항목 | 선택지 | 설명 |
|-----------|--------|------|
| 설명 수준 | 상세 / 간결 | AI 교정 설명의 상세도 조절 |
| 학습 목표 | 자유 입력 | "비즈니스 이메일", "일상 회화" 등 목표 입력 |

## 4. 정책 및 제약사항 (Policies)

- 설명 수준의 유효 값: `detailed` 또는 `concise` (그 외 거부)
- 기본값: `detailed` (상세)
- 프로필 미존재 시 자동 생성
- 변경 즉시 반영 (다음 교정부터 적용)
